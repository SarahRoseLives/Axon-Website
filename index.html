Enterprise-Grade Architecture

Built to scale from a small friend group to a resilient community network.

SQLite + WAL Mode

High-performance local storage. Unlike flat-file systems, AXON uses SQLite with Write-Ahead Logging to handle concurrent chat and file transfers without UI lockups.

Event-Driven Gossip

Efficient propagation. AXON uses a "Rumor Mongering" protocol to sync file libraries across the mesh instantly upon connection, minimizing bandwidth usage.

Distributed Library

Share thousands of files. Your local library is indexed and searchable by peers. Downloads are chunked (512KB) to ensure reliability over Tor latency.

F2F Capabilities

Features designed for intimate, trusted networks.

Web of Trust

Visualize your social circle. Force-directed graph layout shows how you connect to friends-of-friends.

Off-the-Record Chat

Direct, E2E encrypted messaging. Database deduplication ensures clean chat history even on flaky networks.

Instant Search

Search your entire network's shared files instantly. The local index means zero network latency for queries.
